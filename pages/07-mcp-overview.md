# MCP란 무엇인가

MCP(Model Context Protocol)는 인공지능이 외부 기능을 도구처럼 사용할 수 있게 하는 연결 규칙입니다. AI가 게임 서버에 요청하고 결과를 받는 통로라고 생각하면 됩니다.

이 프로젝트는 원격 MCP 서버의 끝말잇기 기능을 사용합니다. API 주소는 `REMOTE_MCP_URL`, 인증 정보는 `MCP_AUTHORIZATION` 환경 변수에 보관합니다.

MCP를 사용하면 게임 규칙과 단어 데이터베이스를 AI 코드 안에 직접 만들지 않아도 됩니다. 게임 전문 서버는 게임 상태를 관리하고, AI는 그 결과를 사용자에게 설명합니다.
