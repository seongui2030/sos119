
## 의존성이란?

의존성은 다른 개발자가 만들어 둔 기능을 내 프로젝트에서 사용하는 것입니다. `package.json`에 필요한 패키지 이름과 버전 범위를 기록합니다.

## 주요 패키지

| 패키지 | 역할 |
| --- | --- |
| `next` | 화면과 서버 API를 함께 만드는 프레임워크 |
| `react` | 화면을 구성하는 라이브러리 |
| `openai` | OpenAI API를 호출하는 공식 라이브러리 |
| `typescript` | 자료형을 검사하는 개발 도구 |
| `@types/react` | React용 TypeScript 타입 정보 |

`package-lock.json`은 실제로 설치된 하위 패키지 버전을 고정합니다. 그래서 다른 컴퓨터에서도 비슷한 환경을 만들 수 있습니다.
