
API 키는 비용이 발생할 수 있는 비밀 정보입니다. `OPENAI_API_KEY`를 `page.tsx`에 넣거나 README에 기록하지 않습니다.

```text
.env.local       공개하지 않음
node_modules/    Git에 올리지 않음
.next/           빌드 결과이므로 보통 올리지 않음
```

음성에는 건강 정보가 포함될 수 있습니다. 실제 서비스로 사용하기 전에는 어떤 데이터가 OpenAI나 MCP 서버로 전송되는지 사용자에게 알려야 합니다. 녹음 데이터를 필요 이상으로 저장하지 않는 것도 중요합니다.

취약점 수정 때 `npm audit fix --force`를 사용하면 Next.js 메이저 버전이 바뀔 수 있으므로 반드시 빌드와 기능 테스트를 다시 합니다.
