# 선수 지식과 준비물

## 필요한 기초 지식

처음 배우는 학생이라면 다음 개념을 조금씩 익히면 좋습니다.

- HTML: 웹 문서의 구조
- CSS: 웹 화면의 꾸미기
- JavaScript: 버튼과 데이터 처리
- TypeScript: JavaScript에 자료형을 더한 언어
- JSON: 프로그램 사이에서 데이터를 주고받는 형식

## 필요한 준비물

Node.js 20.9 이상, npm, VS Code, 마이크가 있는 컴퓨터, OpenAI API 키가 필요합니다. 끝말잇기를 사용하려면 원격 MCP 서버 주소와 인증 정보도 필요합니다.

## 안전한 학습 태도

API 키는 비밀번호처럼 관리합니다. 다른 사람에게 보내거나 GitHub에 올리지 않습니다.
